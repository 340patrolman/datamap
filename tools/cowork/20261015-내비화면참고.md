# 코워크 지시서 — 상용 내비 안내 화면 참고 자료 모으기 (2026-10-15)

소유자 말씀: 「상용 네비게이션 화면처럼 잘 구성해 줘 · 필요하면 앱에 접근해서 따라 해도 되고 · 이미지라도 · 직접 못 하겠으면 프롬프트를 만들어 코워크에게」.
목적: 네비 가르고(경찰 순찰·출동용 웹 내비, `datamap/gargo/`)의 **안내 중 화면**을 티맵·카카오내비 수준으로 다듬기 위한 참고 자료다. 화면 배치를 보고 따라 할 것이다(그림·로고·글꼴 파일을 가져다 쓰지는 않는다).

결과 = `지식베이스/코워크_결과_내비화면_20261015.md` 한 파일 + 그림은 `지식베이스/07_API키/out/navref/`(저장소에 올리지 않음).
열쇠·로그인·결제·앱 설치·약관 동의는 하지 않는다. 공개된 화면만 본다.

## 1. 모을 것 (앱마다: 티맵 · 카카오내비 · 네이버 지도 내비 · 있으면 아이나비)
공개된 곳에서만: 구글 플레이·앱스토어 상세 페이지의 스크린샷, 각 회사의 공식 소개·도움말·블로그·보도자료의 안내 화면 그림.
각 그림마다 결과 파일에 한 줄: 파일 이름 · 출처 주소 · 무슨 화면인가(일반 도로 안내 / 고속도로 / 교차로 확대 / 차로 안내 / 신호 / 단속 카메라 / 밤 화면).

## 2. 그림마다 적을 것 (폰 세로 화면 기준 · 대략 비율이면 된다)
1. **회전 안내 칸** — 자리(위·왼쪽 위 등) · 화면 폭의 몇 % · 높이 · 바탕색 · 화살표 크기 · 남은 거리 글씨 크기(화면 높이 대비) · 길 이름 자리.
2. **다음 회전(그다음)** — 어디에, 얼마나 작게.
3. **차로 안내** — 언제 나오나(몇 m 앞) · 칸 모양 · 갈 차로 표시 방법(색·화살표) · 화면 어디.
4. **교차로 확대·고속도로 나들목 목록** — 나오는 때와 자리 · 목록에 무엇(이름·거리·남은 시간·휴게소 표시).
5. **신호등 정보**(티맵 「신호등 잔여시간」 등) — 있으면 어떻게 보이나(아이콘·숫자 크기·자리·색).
6. **현재 속도·제한속도·단속 카메라** — 자리 · 크기 · 경고 때 바뀌는 모양.
7. **아래 막대** — 도착 시각·남은 시간·남은 거리의 차례 · 높이 · 「안내 종료」 단추가 어디 있는지(막대 위인지 메뉴 안인지).
8. **경로 진행 막대·소통 색 막대** — 있으면 자리(세로·가로)와 모양.
9. **지도 쪽** — 안내 중 지도가 화면의 몇 %를 차지하나 · 내 차 표시 자리(아래 1/3 등) · 지도 기울임(3D) 여부.
10. **밤 화면** — 색 바뀌는 방식.

## 3. 음성 안내 문구 (공식 도움말·소개 글에 있는 것만 · 지어내지 않는다)
회전 예고를 몇 m 앞에서 몇 번 하는지 · 차로 안내 말투 · 과속·카메라·어린이보호구역 말투 · 경로 재탐색 말투. 출처 주소와 함께.

## 4. 정리 (결과 파일 맨 위)
- 세 앱이 **공통으로** 하는 것 5~10줄(예: 「회전 칸은 왼쪽 위 · 남은 거리가 가장 큰 글씨 · 차로는 회전 칸 바로 아래」).
- 앱마다 **다른 점** 몇 줄.
- 가르고에 없는 것 목록(가르고 지금 화면: 위 회전 칸 + 그 밑 신호 한 줄 판 + 왼쪽 세로 소통 막대 + 왼쪽 아래 제한속도·현재 속도 + 아래 도착 막대 + 오른쪽 세로 단추 6개).

## 하지 말 것
- 앱을 설치하거나 로그인하지 않는다 · 유료 자료 · 개인 블로그의 화면 녹화 영상은 출처만 적고 그림을 뜨지 않는다.
- 그림을 가르고에 그대로 넣지 않는다(참고용) — 결과 파일에 「참고 전용」이라 적는다.
