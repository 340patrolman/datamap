## 3. 없는 것 → 만들거나 받아야 함
- **대형마트·편의점 전국 위치**: 소진공 상가정보(이미 storecls·ind-dict 로 쓰는 원자료) 또는 인허가(대규모점포)에서 굽기 — 먼저 storecls 안에 있는지 확인.
- **대중교통 문앞~문앞 시간**: 지금은 배차·영향권·「서울까지」뿐. 1판 = 근사식(걷기 + 배차/2 + 탑승 + 갈아타기 벌점)로 「대략」 표시 · 2판 = 외부 길찾기 API(미결 3).
- **광역버스(M버스·직행좌석) 요금·노선**: 경기 버스 API 로 이미 받는 중앙차로 자료 외에는 없음.
- **교통 요금 규칙 · K-패스/정액권 규칙** — 새 `data/fare-rules.json`.
- **자동차 비용 규칙**(취득세·공채·자동차세·교육세·전기차 감면) — 새 `data/car-rules.json`. 차값·보험·연비·감가는 직접 입력(원자료 없음 · 지어내지 않기).
- **관리비** — 공동주택관리정보시스템(K-apt) 단지별 관리비 원자료(공개) — 2판 후보.

## 5. 계산 묶음
- 처음: 집(realty-afford 계산) + 이사(입력) + 차(차값 + 취득세 + 교육세 + 공채 할인 + 번호판·등록 수수료(확인))
- 매달: 대출 원리금 또는 월세 − 청년월세 지원 + 관리비(입력) + 교통비(편도 요금 × 2 × 출근일 × 4.345 → K-패스·정액권 가운데 싼 것) + 차(기름·충전 = 거리 × 연비 × 단가(입력) + 주차(입력) + 보험/12(입력))
- 해마다: 재산세·종부세(세무 탭 그대로) + 자동차세(− 연납 할인)
- 출퇴근 분: 걷기(영향권) + 기다림(배차/2) + 탑승(근사 · 표시 「대략」) — 차는 reach + 시간대 교통량 보정은 2판
- 거리표: 체크한 시설마다 걸어서 5·10·15분 안 개수 + 가장 가까운 곳 분(직선 × 1.3 근사 표시 또는 stz 길 따라)
