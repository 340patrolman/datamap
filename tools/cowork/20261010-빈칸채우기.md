## 공통 규칙
- 열쇠는 `07_API키\keys.json` 에서만 읽는다. **화면·파일·커밋·로그에 열쇠를 쓰지 않는다.** 커밋 전에 각 키 앞 12자로 `git diff --cached` 를 grep 해서 0 건을 확인한다.
- 시작 전 `git pull origin main`. 커밋 끝줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 판올림 규칙(`index.html`·`sw.js` 의 `?v=`)은 **지도 코드(js)를 고칠 때만** — 자료 파일(`data/*.json`)만 바꿀 때는 판을 올리지 않는다.
- **Cloudflare(맛보기 중계)는 하지 않는다** — 형님이 직접 같이 할 일이다.
- 지어낸 값 금지. 막히면 억지로 우회하지 말고 막힌 지점·오류 원문을 결과 파일에 적는다.
- 결과는 `07_API키\코워크_결과_20261010.md` 에 과제마다 「✅ 끝 / ⏳ 진행 중 / ❌ 막힘」 + 숫자 + 다음 할 일로 적는다. 끝나면 형님께 「Claude Code 에서 '07_API키 코워크_결과_20261010 이어서'」라고 알린다.

## 과제 1 — 국세청 근로소득 전국판 (먼저 · 30분 안팎)
도구는 Claude Code 가 전국판으로 고쳐 두었다(v2.96.0 · `tools/region/guTax-bake.py`).
1. `py -3.12 -X utf8 tools/region/guTax-bake.py` (필요: `data\r\index.json` — 없으면 `tools/region/publish-data.py manifest` 로 먼저 만든다)
2. 끝에 찍히는 **「시도별 시군구 수」** 와 **「못 이음 …」 줄 전부**를 결과 파일에 그대로 붙인다. 기대: 17개 시도 · 240곳 이상.
3. 확인: `data/gu-tax.json` 에서 서울 강남구(11680) wage 가 이전 값(8,520만 원 · 2023)과 같은지 · 부산 해운대구(26350)·강원 춘천시(51110)에 wage 가 생겼는지.
4. 이상 없으면 `data/gu-tax.json` 만 커밋·푸시. 「못 이음」이 20줄 넘으면 커밋하지 말고 결과만 적는다(Claude Code 가 이름 잇기를 고친다).

## 과제 2 — 동별 전입·전출 (진행 중이던 것 마무리)
지도와 굽는 도구는 준비돼 있다(v2.93.0 · `tools/region/mig-bake.py` · 파일이 없으면 보정 없이 동작).
1. 서초·강남 16묶음 받기를 끝내고 묶음마다 합계 검증(전에 한 방식: 총인구 = 나이·성별 칸 합).
2. **기록 단위 원자료를 동·달마다 센 CSV 로 바꾼다** → `07_API키\out\mig\서초강남_전입전출.csv`
   - 열: `행정동코드`(10자리) · `기간`(YYYYMM) · `전입`(그 동으로 들어온 수) · `전출`(그 동에서 나간 수)
   - **나이·성별이 있으면** 같은 폴더에 `…_나이별.csv` 로 따로(열: 행정동코드 · 기간 · 나이대(10세) · 성별 · 전입 · 전출) — 지금 도구는 안 쓰지만 다음 판(나이대별 보정)에 쓴다.
   - 같은 구 안 이사(동 → 동)는 한쪽 동의 전입·다른 동의 전출로 **둘 다** 센다.
3. `py -3.12 -X utf8 tools/region/mig-bake.py "행정안전부 <정확한 자료 이름> (<받은 날>)"` → 찍힌 「동 n · 시군구 n · 기간」을 적고 `data/mig-dong.json` 커밋·푸시.
4. 전국으로 넓히는 길 조사만(받지 말고): 3개월 묶음에 7분이면 전국은 몇 시간·며칠인지 계산 · 한 번에 받는 파일 내려받기·다른 API(KOSIS 국내인구이동통계는 시군구까지인지 읍면동까지인지) 비교표.

## 과제 3 — 강원·전북 동별 아파트 값 (며칠에 걸쳐 · 하루 한 번)
지금 강원·전북은 실거래 단지를 행정동에 잇지 못해 동 칸이 비어 있다(브이월드 주소 하루 한도).
1. 날마다 `py -3.12 -X utf8 tools/region/home-bake.py geo` → 한도(OVER_REQUEST_LIMIT)에서 멈추면 그날 끝.
2. 남은 지번이 0 이 되면 `home-bake.py build` → `publish-data.py push 51 52` → `homeref-bake.py`(기본 경로 data/r/*/home.json) → `data/home-ref.json` 커밋·푸시.
3. 매일 남은 지번 수를 결과 파일에 한 줄씩.

## 과제 4 — 조사만(받지 말고 표로)
1. **동(읍면동) 단위 생활인구·카드 매출을 공개하는 시도가 서울·경기 말고 있는가**(부산·대구·인천·광주·대전·울산·세종·제주 우선). 칸: 시도 · 자료 이름 · 주소 · 단위(동/격자/시군구) · 기간 · 갱신 주기 · 이용 조건(공공누리 유형) · API/파일.
2. **업종 × 나이(연령대) 카드 소비를 전국으로 공개한 자료가 있는가**(지금은 서울시 상권분석서비스 비율을 전국에 근사로 쓴다). 무료·공공만. 유료(카드사 빅데이터 판매)는 「유료」라고만 적는다.
3. **광명시 장래인구 확인**: KOSIS 주민등록 인구로 광명시 2022·2023·2024·2025·2026(최근 달) 실제 인구를 적고, 통계청 추계(2022 기준) 2026년 296,396명과 비교 — 재건축 입주 때문에 추계가 실제와 벌어졌는지.
