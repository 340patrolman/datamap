## 과제 1 — 카카오모빌리티 길찾기 API 약관 원문 (먼저 · 30분)
가르고(출동 내비)는 걸리는 시간 보정을 ITS 공공 실측으로만 하고, 카카오 길찾기 결과는 「그 자리에서 맞대 보기」에만 쓰기로 했다(소유자 2026-10-15 · 규칙 RULE-NAV-4). 근거를 원문으로 굳힌다.
1. 카카오 개발자(developers.kakao.com)·카카오모빌리티 개발자 문서에서 **길찾기(Directions) API 의 이용약관·운영정책** 원문을 찾는다.
2. 다음 조항이 있는지, 있으면 원문 한 대목 + 주소: ① 결과 저장·캐시 ② 결과로 만든 자료(통계·보정값)의 2차 이용·재배포 ③ 무료 하루 한도 ④ 비영리·공공 목적 예외.
3. 이미 받은 개발자 게시판 답(「임시 캐싱 등의 방법으로 API 호출 및 이용은 금지」)의 글 주소를 다시 찾아 적는다.
4. 결론 한 줄: 「그 자리 비교(저장 0)는 되고 / 보정값 저장은 안 된다」가 원문과 맞는지 · 다르면 무엇이 다른지.
