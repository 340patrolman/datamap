## 4. 계산식 초안 (값은 3장 확인 뒤 규칙 파일에서 읽음)
- **매매 상한 P** = 가장 작은 값 { 가진돈 + LTV×P , 가진돈 + DSR 한도 원금 , 가진돈 + 상품 한도 } − (취득세 등(P) + 중개(P) + 채권 할인·인지세(P) + 법무사) → P 가 양쪽에 있으므로 **반복 계산(이분법)** 으로 푼다.
- **DSR 한도 원금** = (연소득 × DSR비율 − 기존 원리금) 을 (금리 + 스트레스 가산)·만기로 원리금 균등 역산.
- **전세 상한 D** = 가진돈 + 가장 작은 값 { D×보증비율, 상품 한도, 소득 기준 한도 } − 중개(D, 임대차).
- **월세** = 보증금 B 를 고르면 월세 M 상한 = 월소득 × 부담 비율 · 청년월세 지원 대상이면 M − 지원액을 같이.
- **청년·공공임대** = 자격 판정(예/아니오/공고 확인) + 확인된 임대료 기준만.
- 각 결과에 steps(과정) · warn(미확인·가정) · 「막힌 이유」.
