# 데이터 압축지도 — 서울·경기

공공데이터를 한 장의 지도에 겹쳐 보는 앱(교통·치안·상권·인구·생활시설). 서버 없음 · 통신은 같은 사이트의 자료 파일뿐.
원래 [교통경찰 게임(traffic-game)](https://github.com/340patrolman/traffic-game) 안의 `map2d.html` 이었고, 2026-10-04 v1.0.0 에서 따로 떼었다
(게임 저장소의 `map2d.html` 은 이 앱으로 넘겨 주는 길잡이 — T-Book 이 쓰는 `#lat=..&lon=..&ly=..&h=..&here=1&gps=1` 주소는 그대로 이어진다).

* 구성·층·자료·굽는 법: `MAP2D.md`
* 굽는 도구: `tools/` (키는 저장소 밖 `07_API키/keys.json` 에서만 읽는다 — 저장소에 키 없음)
* 검색 노출 막기: 모든 쪽에 `noindex` · 사이트에서 문서·도구 제외(`_config.yml`)
* 출처: 각 자료 파일의 `source` 칸과 지도 아래 「자료 출처」
