# 코워크 실행 지시 — 2026-10-18 형님 집 PC (Claude Code 작성)

너는 형님(소유자) PC에서 일한다. 저장소 `datamap` 의 **CLAUDE.md 절대 규칙**을 먼저 읽고 따른다.

## 공통 규칙
- 열쇠는 `07_API키\keys.json` 에서만 읽는다. **화면·파일·로그에 열쇠를 쓰지 않는다.**
- **글 올리기·문의 제출·활용신청 「신청」 단추·약관 동의·로그인·본인 인증은 하지 않는다** — 그 단계에 닿으면 멈추고 형님께 「여기서 눌러 주세요」라고 말한다. 형님이 누른 뒤 이어서 한다.
- 지어낸 값 금지 · 원문은 짧게(한 대목 15단어 안) + 주소(URL).
- 저장소에 커밋하지 않는다. 결과는 `07_API키\코워크_결과_20261018.md` 에 과제마다 「✅ 끝 / ⏳ 진행 중 / ❌ 막힘」 + 근거 주소 + 다음 할 일.
- 끝나면 형님께 「Claude Code 에서 '07_API키\코워크_결과_20261018.md 읽고 이어서 해' 라고 말씀하세요」.

## 과제 1 — 신호계획 「요일 번호」 뜻 찾기 (조사 · 먼저)
경찰청 신호계획 요일표(`PLAN_DY` 1~7 · UTIC tsihub `PlanCrossRoadInfoService/getPlanCRWDInfo` · 공공데이터포털 15056569 「교차로계획정보서비스」 같은 칸)의 **1~7 이 각각 무슨 요일인지** 공식 문서로 확인한다. 지금은 「1=일 … 7=토」를 서울 자료 모양에서 짐작해 쓰고 있다. 인천·대구·대전은 거의 모든 교차로가 「1→4번 · 2→2번 · 3~6→1번 · 7→3번 계획」이라 짐작이 흔들린다.
1. UTIC 개방데이터 화면(www.utic.go.kr › 개방데이터 · tsihub.utic.go.kr)의 신호 관련 **명세서·첨부(hwp·pdf·xlsx)** 를 열어 PLAN_DY(또는 「계획요일」) 코드표를 찾는다.
2. 공공데이터포털 15056569 의 「활용가이드」 첨부도 같은 칸을 본다.
3. 찾으면 코드표를 그대로 옮기고 주소. 못 찾으면 **UTIC 문의 초안만**(올리지 않음): 「PlanCrossRoadInfoService getPlanCRWDInfo 의 PLAN_DY 1~7 이 각각 어느 요일인지 · 0 의 뜻 · 특수일(getPlanCRHDInfo)의 HOLY_PLAN_MM/DD 가 0 인 줄의 뜻」.

## 과제 2 — 천문연 음양력 API 활용신청 (형님이 「신청」만 누르면 됨)
공공데이터포털 「한국천문연구원_음양력 정보」(LrsrCldInfoService) — 지금 열쇠로 부르면 403(활용신청 안 됨).
쓰임: ① 손 없는 날(이사가 몰리는 날 → 골목 이삿짐 차량 · 네비 가르고 골목 시간 가산) ② T-Book 공휴일 2029~2030 음력 명절 대조.
1. 크롬에서 공공데이터포털 해당 API 상세 → 「활용신청」 화면까지 연다(형님 로그인은 형님이).
2. 활용 목적 칸에 「경찰 교통업무 보조 연구개발 — 교통 혼잡 예측(이사 많은 날)과 근무표 공휴일 확인」 · 상세 기능은 「음력 날짜 조회」만.
3. **「신청」 단추 앞에서 멈추고** 형님께 누르시라고 말한다. 눌렀으면 결과 파일에 「신청함(자동승인 여부)」.

## 과제 3 — 서초구 도로 공사·점용 알림의 공개 출처 (조사)
형님 말씀(10-15): 「공사는 서초구에서 미리 알림을 주기는 하는데」. 네비 가르고가 골목 공사를 알 수 있게 공개 출처를 찾는다.
1. 서초구청 누리집 공지·고시공고·「도로굴착·점용 허가」 게시판 · 서울시 「도로굴착 공사 정보」(열린데이터광장 · 서울시 도로공사 현황 API 가 있는지) · 생활안전지도 공사 정보.
2. 각 출처마다: 주소 · 담긴 칸(위치 글/좌표 · 기간 · 시간 · 통제 내용) · 갱신 주기 · 이용 조건(공공누리 몇 유형) · 서초 최근 건수.
3. 받지는 않는다(Claude Code 가 받아 굽는다) — 표만.
